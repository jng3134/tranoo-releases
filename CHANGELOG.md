# Changelog

All notable public Android beta releases of Tranoo are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and version names follow [Semantic Versioning](https://semver.org/) with a beta pre-release suffix (`MAJOR.MINOR.PATCH-beta.N`).

## Unreleased

## 1.0.0-beta.11

- Richer property details UI (viewing CTA, gallery fade, facts layout, sticky actions)
- Clearer map browsing and property-map presentation
- Visit management layout and action polish
- Theme-consistent home header logo (light / dark)

## 1.0.0-beta.10

- Fixed keyboard/IME layout handling across all listing creation and editing form steps (prevents layout jumping, collapsing, or field clipping)
- Added automatic focus bring-into-view for all text and numeric inputs
- Added decimal comma normalization for price and surface inputs on French and Malagasy keyboards
- Instant language preference switching during onboarding without activity recreation or loading flash
- Committed chosen language to system per-app locales upon onboarding completion

## 1.0.0-beta.9

- Redesigned onboarding for language, theme, currency, and location
- Stronger locale switching and theme (light/dark/system) handling
- Clearer offline/error messaging in key flows
- Property details readability and performance refinements

## 1.0.0-beta.8

- Visit management screen for property viewing requests
- Feature suggestion moderation and pending suggestions in CreateListing
- Collection hero spotlight and clearer explore sections
- Collapsing home headline and home/profile layout refinements
- Faster startup/splash (including dark splash) and chat/map polish

## 1.0.0-beta.7

- Firebase push notifications for listing and messaging alerts
- Publish listings as an agency when membership allows
- Feature suggestions while editing listing amenities
- City/district autocomplete improvements on create listing
- Cursor-based pagination for explore, favorites, notifications, and conversations
- Clearer home/collection empty states and visual polish (theme + shared UI)

## 1.0.0-beta.6

- Collection refresh and owned-agencies screen test / UI assertion fixes

## 1.0.0-beta.5

- Localized notification and conversation screens (EN / FR / MG)
- Stronger real-time messaging with WebSocket connectivity recovery and conversation sync
- Document vault status line version label fix

## 1.0.0-beta.1

- Initial public beta release

- Localized notification and conversation screens (EN / FR / MG)

- Document vault status line version label fix
